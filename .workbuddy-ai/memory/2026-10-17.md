## 2026-10-17 — UI fixes: logout, gutters, 3D mobile, long task labels

### Logout
- New `src/components/LogoutButton.tsx` — visible control using the existing
  `useAuth().logout()`; navigates to `/login` in `finally` because the provider
  clears local state whether or not the request succeeds.
- Wired into the AppShell `accountSlot` (sidebar footer **and** mobile drawer —
  both render the same slot) via `WorkspaceLayout`, and into the `WorkspaceList`
  header (that screen has its own chrome).

### Spacing
- One gutter everywhere: `px-4 sm:px-6 lg:px-8` on `PageContainer`, `PageHeader`,
  the hand-written page headers (Dashboard/Projects/Members/Notifications/
  Settings/ProjectLayout) and every marketing section.

### 3D scene (real causes, both fixed)
1. Fixed-pixel card offsets (±140px, cards 170–210px) needed ~504px of width; a
   phone container is ~288–358px, so cards were clipped by `overflow-hidden`.
   Fix: one `scale()` on the 3D stage derived from a `ResizeObserver`, floor 0.55.
2. The `@keyframes` animated the independent `translate` property **on top of**
   the inline `transform`'s `translate(-50%,-50%)`, double-applying the centring
   offset. Fix: float is computed in the same rAF transform string.

### Task labels
- List: title `max-w-[min(26rem,55vw)] truncate` + `title` attr; assignee
  `max-w-[10rem] truncate`.
- Detail h1: `min-w-0 break-words`, Edit button `shrink-0`.
- Subtasks/comments: `min-w-0 break-words`, `shrink-0` controls, `break-words`
  on comment bodies.
- `LabelChip`: `max-w-full min-w-0` + truncating child + `title`.

### Verification (real API harness + preview, headless Chrome)
21/21 checks: homepage at 320/390/834/1440 + landscape 844×390 (no horizontal
scroll, 5 cards inside their container); visible Log out on desktop and in the
mobile drawer; logout redirects to `/login`; `/workspaces` after logout redirects
to `/login`; task list at 390/1440 truncates long titles inside their cell; task
detail with a 180-char unbroken title wraps to 9 lines with no overflow; no
console errors.

**Trap:** `documentElement.scrollWidth` over-reports when a table sits in an
`overflow-x-auto` wrapper — the page cannot actually scroll. Check
`window.scrollX` after `scrollTo(9999,0)` instead.
**Trap:** the rate limiter is in-memory but survives `TaskStop` (the bash wrapper
dies, the node child does not). Kill the `boot-real-api` node process by PID or
the next harness instance dies on `EADDRINUSE 5051` while the old one keeps
serving stale counters.

Built a premium public marketing homepage for PROJEX at `/`.

### Files created
- `src/pages/MarketingHomepage.tsx` — homepage with nav, hero, features, workflow, showcase, CTA, footer
- `src/components/marketing/Scene3D.tsx` — CSS 3D floating cards visualization, lazy-loaded

### Files changed
- `src/routes/index.tsx` — replaced `/` redirect with MarketingHomepage route
- `index.html` — added Open Graph and Twitter Card meta tags
- `vite.config.ts` — removed advancedChunks (reverted manual chunking from earlier today)

### Design decisions
- Uses shell components (`@/components/ui/shell`) for the public path to keep initial bundle small
- Scene3D is lazy-loaded via `React.lazy` + IntersectionObserver; only loads when hero scrolls into view
- 3D effect is CSS-only (perspective, transform-style, rotateX/Y/Z); no Three.js or new dependencies
- Respects `prefers-reduced-motion`: animation stops, cards sit in static arrangement
- Auth-aware CTAs: authenticated users see "Go to app", anonymous see "Get started free"
- Dashboard preview in showcase section built with plain markup using design tokens

- Scene3D lazy chunk: ~4.9 KB rendered
- Build passes: typecheck 0 errors, lint 0 errors, build exit 0
